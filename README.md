# Marco Del Fava

I'm a biomedical engineering graduate student at UC Davis working at the intersection of human intracranial electrophysiology and scientific software engineering.

I develop Python tools for neural acquisition data, spike sorting, experimental synchronization, and data validation. I'm particularly interested in making research software reliable, reproducible, and easier for other scientists to use.

### Selected work

- **[Neural processing and sorting](https://github.com/BarkBarkBarkBarkBarkBarkBark/zlab_sorting_script)** — Intan acquisition workflows, SpikeInterface integration, automated curation, and regression tests.
- **[Agent-assisted software engineering](https://github.com/BarkBarkBarkBarkBarkBarkBark/Hosaka)** — Extensible software platform with schema validation, caching, and automated tests.
- **[Schema caching regression tests](https://github.com/BarkBarkBarkBarkBarkBarkBark/Hosaka/blob/main/tests/extensions/test_schema_cache.py)** — A focused example of testing changed and invalid schemas while eliminating redundant validation.
